# 📚 The English Language Guide
Plataforma gratuita para aprender inglés desde nivel básico hasta avanzado, con ejercicios interactivos.

## 🚀 Tecnologías
- React + JSX
- CSS3
- GitHub Pages

## 📦 Instalación y uso
```bash
# Instalar dependencias
npm install

# Ejecutar en local
npm start

# Publicar en GitHub Pages
npm run deploy
